# Генератор лабиринтов и поиск пути (Maze Visualizer)

Учебное десктопное приложение на Java (Swing) для генерации лабиринтов и визуализации алгоритмов поиска кратчайшего пути с подсчётом метрик эффективности.

## Текущая функциональность (промежуточная версия)
* Генерация лабиринта алгоритмом **Depth-First Search (DFS)**.
* Поиск кратчайшего пути алгоритмом **Breadth-First Search (BFS)**.
* Графический интерфейс с автоматическим масштабированием сетки и отображением метрик (количество исследованных ячеек, время работы).
* Модульная структура пакетов (`model`, `algorithm`, `ui`) с применением паттернов проектирования (*Strategy*, *Builder*).

## Планы по доработке
* **Развитие пользовательского интерфейса (UI):** переработка компоновки окна, добавление выпадающих списков выбора алгоритмов, полей настройки визуализации, кнопок навигации, блока учебной справки и более выразительной цветовой индикации состояний ячеек.
* **Новые алгоритмы:** добавление алгоритма генерации **Kruskal** и алгоритма поиска пути **A\*** (с выбором через *Factory Method*).
* **Гибкая настройка сетки:** ввод произвольных размеров лабиринта (ширина и высота) с валидацией и интерактивный выбор точек старта и финиша.
* **Динамическая визуализация:** пошаговая анимация процессов генерации и поиска с регулировкой скорости (паттерн *Observer*).
* **Повторный запуск и надёжность:** сброс только найденного пути для перерешения другим алгоритмом на той же карте и обработка непроходимых лабиринтов.

## Требования
* **JDK 17** или выше
* **Apache Maven 3.8+**

## Инструкция по сборке
В корневой директории проекта выполните команду:
```bash
mvn clean package
```
Maven выполнит модульные тесты и соберёт исполняемый Fat-JAR в директории `target/`.

## Пример запуска
```bash
java -jar target/maze-visualizer-0.1-SNAPSHOT.jar
```

## Использованные сторонние библиотеки
* **FlatLaf (`com.formdev:flatlaf:3.2.5`)** — современная тема оформления графического интерфейса Java Swing.
* **JUnit 5 Jupiter (`org.junit.jupiter:junit-jupiter:5.10.0`)** — фреймворк для модульного тестирования (`scope: test`).
